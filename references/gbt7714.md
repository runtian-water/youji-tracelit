# GB/T 7714-2015 参考文献

## 1. 范围

- 正式参考文献只含 primary `✓`（原始研究）。
- 背景综述单列“背景文献”，不计入 K。
- 预印本单列“预印本（未评审）”，只列 DOI 核验 pass 的预印本；无 DOI 的落 `○ D1`，默认不进正式参考文献。
- `○` 标 `[待核]`，不得进答辩 PPT 参考文献，也不得冒充已核验。
- 缺字段一律标注，不得补造。

## 2. 作者

- 中文：前 3 位，第 4 位起用“等”。例：`张三, 李四, 王五, 等.`
- 英文：姓全大写，名用首字母，逗号分隔；第 4 位起用 `et al.`。例：`SMITH J, DOE A, LEE B, et al.`
- `author_count` > 3 时才加“等/et al.”；正好 3 位不加。

## 3. 类型标识

| 类型 | 标识 | 备注 |
|---|---|---|
| 期刊论文 | `[J]` | 卷(期): 起页-止页 |
| 会议论文 | `[C]` | 会议名、地点、年、页 |
| 图书 | `[M]` | 出版地: 出版社, 年 |
| 图书章节 | `[M]//` | 书名、编者、页 |
| 学位论文 | `[D]` | 学校、年 |
| 报告 | `[R]` | 机构、编号、年 |
| 标准 | `[S]` | 标准号、年 |
| 预印本 | `[EB/OL]` | DOI 或 OpenAlex URL |
| 数据集 | `[DS/OL]` | DOI 或 OpenAlex URL |

## 4. 格式

期刊：

```
[1] 作者. 题名[J]. 刊名, 年, 卷(期): 起页-止页. DOI: 10.xxxx/xxxx.
```

会议：

```
[2] 作者. 题名[C]//会议名. 地点: 出版者, 年: 起页-止页. DOI: 10.xxxx/xxxx.
```

图书：

```
[3] 作者. 书名[M]. 出版地: 出版社, 年: 起页-止页. DOI: 10.xxxx/xxxx.
```

图书章节：

```
[4] 作者. 章节题名[M]//编者. 书名. 出版地: 出版社, 年: 起页-止页.
```

学位论文：

```
[5] 作者. 题名[D]. 学校, 年.
```

预印本：

```
[6] 作者. 题名[EB/OL]. (发布日期)[引用日期]. https://doi.org/10.xxxx/xxxx.
```

## 5. 缺字段

- 单页只写一页：`first_page == last_page` 时折叠为 `775`，不写 `775-775`。
- 缺卷/期/页：写 `[卷期页待补]`，仅草稿可用；整块参考文献加“草稿：正式提交前必须补齐或删除”。
- 无 DOI 的预印本/数据集：URL 用 `https://openalex.org/{openalex_id}`。
- 无作者：写 `[作者待补]`，不得编造。
- 无年份：写 `[年份待补]`，不得估算。

## 6. 标题与标点

- 表内标题可截断：中文 ≤40 字，英文 ≤80 字符；参考文献用完整标题。
- 中文文献用中文标点；英文文献用英文标点。
- DOI 统一写 `DOI: 10.xxxx/xxxx.`，不加 `https://doi.org/` 前缀到正文；URL 形式只用于 `[EB/OL]`。

## 7. 排序与编号

- 按正文出现顺序编号；未在正文引用时按第一作者字母/拼音排序。
- 背景文献单独编号，不打断正式参考文献的连续编号。
- 预印本不进入正式编号；如需列出，单列“预印本（未评审）”。
