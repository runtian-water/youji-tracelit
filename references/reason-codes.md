# 理由码

## 1. 双轨判定

| 代码 | 标签 | 理工含义 | 社科含义 | 需要的证据 |
|---|---|---|---|---|
| T1 | 主题不符 | 不在研究主题内 | 不在研究主题内 | 标题即可 |
| S1 | 体系/对象不符 | 材料体系/样本/数据集不同 | 人群/样本/案例不同 | 摘要中的体系或样本描述 |
| M1 | 手段/方法不符 | 合成/表征/算法/设计不同 | 问卷/实验/访谈/文本方法不同 | 摘要中的方法描述 |
| C1 | 条件/情境不符 | 温度/浓度/规模/训练条件不同 | 地区/时间/政策情境不同 | 摘要中的条件或情境描述 |
| I1 | 指标/结果不符 | 效率/精度/产率/误差口径不同 | 变量/结果指标不同 | 摘要中的指标或结果描述 |
| R1 | 已撤稿 | — | — | `retraction_status=retracted` 或 Crossref update-to |
| P1 | 类型不符 | paratext/erratum/peer-review/editorial/letter/libguides/other/supplementary-materials/conference-abstract | 同左 | OpenAlex `type` |
| Y1 | 年份越界 | 早于目标窗口 | 早于目标窗口 | `year` |
| L1 | 语言不符 | 不在语言范围 | 不在语言范围 | `language`；默认 en 模式不产生 |
| V1 | 版本重复 | 预印本与已发表同时命中 | 同左 | `version_duplicate=true` |
| D1 | 无 DOI | — | — | `doi=null` |
| D2 | DOI 无法解析 | — | — | Crossref/DataCite 404 |
| D3 | 标题不一致 | — | — | 相似度 <0.85 或 CJK/译名无法比对 |
| D4 | 核验服务不可用 | — | — | Crossref/DataCite 无响应 |
| E1 | 证据不足 | — | — | 无摘要、evidence 为空或未覆盖该维度 |

- `P1` 默认可用：API 层不按类型过滤，脚本按 `accepted_types` 判。若用户显式加了 `type=`，P1 只在 `type=null/unknown` 时命中。
- `P` 只收 DOI 核验 pass 的预印本；无 DOI 的预印本落 `○ D1`，不进 `P`。

## 2. 三分语义

- `✓` 纳入：语义符合且 DOI 核验 pass。
- `×` 排除：明确不符合，只能取 R1/P1/Y1/L1/V1/T1/S1/M1/C1/I1。
- `○` 待核：无法确认，取 D1/D2/D3/D4/E1；不计入纳入数。

## 3. First-fail 顺序

```
R1 → P1 → Y1 → L1 → V1 → T1 → S1 → M1 → C1 → I1 → D1 → D2/D3/D4 → E1
```

每条只记一个主因。条件有证据时必须判 `C1`，不得塞进 `M1`；指标有证据时必须判 `I1`，不得塞进 `M1` 或 `C1`。

## 4. 计数不变量

- `X = Σ × 理由码`
- `O = Σ ○ 理由码`
- `K = primary ✓`（原始研究）
- `B = review/background ✓`（背景综述/奠基；不占 K）
- `P = preprint ✓`（预印本，未评审；只收 DOI pass）
- `X + O + K + B + P = M`
- `K ≥ 3`（循迹/溯迹）；不足时先调类型/主题词，再放宽年份。
- 语义通过但 DOI 失败：计入 `O` 的 `D2/D3`，在复现块单列，不计入 `K`。
- 只有 `B`/`P`、没有 primary 研究时，视为样本不足，不得以“候选够 8 条”收尾。

## 5. 图例模板

只输出本轮出现的码。示例：

```
✓ 纳入　○ 待核（不计入纳入数）　× 排除
R1 已撤稿｜结论不可信｜自查：看期刊撤稿声明
Y1 年份越界（<{起始年}）｜太老，方法可能过时｜自查：看 publication_year
S1 体系/对象不符｜材料/样本和你不同｜自查：看摘要体系或样本
M1 手段/方法不符｜技术路线/研究设计和你不同｜自查：看摘要方法段
C1 条件/情境不符｜温度/浓度/地区/政策情境不同｜自查：看摘要条件段
I1 指标/结果不符｜效率/精度/变量口径不同｜自查：看摘要结果段
D1 无 DOI｜预印本/报告，先别引用｜自查：手动搜标题
D2 DOI 无法解析｜Crossref/DataCite 都查不到｜自查：点 DOI
D3 标题不一致｜DOI 指向的标题对不上｜自查：比对 DOI 落地页
D4 核验服务不可用｜本轮暂时查不了 DOI｜自查：稍后重试
E1 证据不足｜摘要缺失或没提到关键信息｜自查：读全文再定
```

## 6. 边界例子（盲评校准）

| 例子 | 判 | 理由 |
|---|---|---|
| 钙钛矿用于光解水/光电探测器 | T1 | 应用主题不同 |
| 钙钛矿忆阻器 | S1 | 器件/对象不同 |
| 表面掺杂、缺陷工程、载流子管理 | M1 | 同一对象，手段不同 |
| 测 GB 复合速度而非钝化 | M1 | 研究手段不同 |
| 温度/浓度/规模不同 | C1 | 条件不同 |
| 效率 vs 稳定性 vs 精度 | I1 | 指标不同 |
| 综述/观点/Preview | B | 背景，不计 K；category 用 review/background |

判定顺序仍是 first-fail：先看主题，再看对象/体系、手段、条件、指标。应用场景不同优先 T1；同一主题但器件/材料体系不同用 S1；不要把“手段不同”写成 T1。

## 7. 特殊规则

- `L1` 只在未加语言过滤或 `language=null` 时使用；默认 `en` 模式不产生 L1。
- `V1` 只用于预印本/已发表版本对；普通重复由脚本去重，不进入审计表。
- `D3` 对 CJK/译名是“无法比对”，不是“标题错误”；不得判 `×`。
- `is_retracted=null` 写“未知”，不得写“未撤稿”。
- `R1` 永不进入 `✓`，包括综述和预印本。
